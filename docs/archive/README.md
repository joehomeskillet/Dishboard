# Dokumentationsarchiv

Hier liegen abgeschlossene, ersetzte oder widersprüchlich gewordene Planungs-,
Übergabe- und Umsetzungsnotizen. Sie bleiben zur Nachvollziehbarkeit vollständig
erhalten, gelten aber nicht als aktuelle Spezifikation oder Betriebsanweisung.

Die Ablage ist nach Archivierungsmonat gruppiert. Unterhalb des Monats bleibt die
frühere Verzeichnisstruktur erhalten. Aktuelle Dokumente sind im
[Dokumentationswegweiser](../README.md) aufgeführt.
