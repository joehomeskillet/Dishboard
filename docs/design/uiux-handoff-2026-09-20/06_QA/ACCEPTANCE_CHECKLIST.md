# Acceptance Checklist

- [ ] Menüs & Bausteine und Einstellungen besitzen kontextsensitive linke Untermenüs.
- [ ] Untermenüs verschwinden, wenn ein anderer Hauptbereich aktiv ist.
- [ ] Keine horizontale Haupt-Untermodulnavigation mehr.
- [ ] Alle Arbeitsseiten nutzen volle sinnvolle Breite.
- [ ] Einheitlicher Seitenkopf und genau eine klar erkennbare Primäraktion.
- [ ] Einheitliche Statusbar vorhanden; keine bedeutungslosen Platzhalter.
- [ ] Filter sehen gleich aus und sind zurücksetzbar.
- [ ] Tabellen/Listenzeilen sind kompakt und gleich aufgebaut.
- [ ] Statusbadges haben Text, nicht nur Farbe.
- [ ] Empty States erklären Zustand + nächsten Schritt.
- [ ] Formulare gruppieren Pflicht/Häufig/Optional logisch.
- [ ] Seltene technische Optionen sind progressiv offengelegt.
- [ ] Keine Kernfunktion, Route oder Berechtigungsprüfung verloren.
- [ ] 360px, 768px, 1024px und 1440px geprüft.
- [ ] Keyboard/Fokus/Labels geprüft.
- [ ] Vorher-/Nachher-Screenshots je Modul erzeugt.
