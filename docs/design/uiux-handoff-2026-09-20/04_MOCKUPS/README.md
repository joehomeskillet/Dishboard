# HTML Mockups

Öffne die Dateien direkt im Browser. `01_listenansicht.html` zeigt das gemeinsame Listenmuster, `02_detail_editor.html` Detail/Edit, `03_rezepte.html` Rezeptübersicht, `04_kalkulation.html` einen geführten leeren Workflow. Die Mockups sind absichtlich frameworkneutral und sollen in bestehende Flask/Tabler-Komponenten übersetzt werden.
