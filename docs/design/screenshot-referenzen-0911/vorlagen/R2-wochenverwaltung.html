Cafeteriapläne gehören zu einer Kalenderwoche. Das reguläre Mittagsangebot ist von Montag bis Freitag.

Was passiert beim Kopieren?
Vor dem Kopieren müssen Quellwoche, Zielwoche und die im bestehenden System unterstützte Wirkung angezeigt werden. Es wird durch diese Referenz keine neue Kopierfunktion definiert.
