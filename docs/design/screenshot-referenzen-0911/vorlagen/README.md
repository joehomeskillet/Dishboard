# Isolierte Referenzseiten – keine produktive Anwendung

Diese HTML-Dateien erzeugen die Sollbilder. Sie enthalten ausschliesslich Beispieldaten und keine Verbindung zu Dishboard, keine Formularschreibwege und keine produktive Speicherung oder Veröffentlichung. Die meisten Buttons illustrieren lediglich Position und Beschriftung. Native Aufklappbereiche können geöffnet werden; dies belegt keine fachliche Funktion.

**Nicht als zweiten Frontendunterbau übernehmen.** Für die Umsetzung bleiben installierte Tabler-Komponenten, Jinja-Templates, bestehende Fonts/Icons und die echten Formularverträge massgeblich. Die hier enthaltenen SVG-Zeichnungen sind nur Renderingbestandteile, kein Auftrag für eine neue Iconbibliothek. Keine eingebundenen Fontdateien oder externen Assetdienste.

Die Druckansicht ist ein HTML-Layoutbeispiel, kein erzeugtes PDF. Die Übersicht bei 390 CSS-Pixeln illustriert Umordnung, nicht einen absolvierten Nutzer-/Touchtest. Sämtliche Freigaben stehen ausschliesslich in `../UI_REFERENZEN.md`.
