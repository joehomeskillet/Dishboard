# UI Review Checklist v2

- [ ] Haupt-/Kontextnavigation entspricht dem Manifest
- [ ] keine horizontale Doppel-Navigation
- [ ] eine klare Primäraktion
- [ ] Status verständlich und konsistent
- [ ] keine irrelevanten Felder permanent sichtbar
- [ ] kein unnötiger vertikaler Leerraum
- [ ] Desktopbreite sinnvoll genutzt
- [ ] mobile Darstellung ohne Standard-Horizontalscroll
- [ ] Filterbar entspricht gemeinsamem Pattern
- [ ] Listen-/Tabellenaktionen konsistent
- [ ] Empty State erklärt nächsten Schritt
- [ ] Bilder angemessen dimensioniert
- [ ] Keyboard-Fokus sichtbar
- [ ] Status nicht nur farbcodiert
- [ ] bestehende Validierung/Berechtigungen funktionieren
- [ ] Vorher/Nachher-Screenshot vorhanden
- [ ] häufigster Workflow mindestens gleich schnell, idealerweise kürzer
