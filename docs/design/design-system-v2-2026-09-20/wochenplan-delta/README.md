# Dishboard – Wochenplan UI/UX Delta

Dieses Paket enthält **nur den aktuellen Wochenplan-Auftrag** und die dazugehörigen Referenzbilder.

Es ersetzt **nicht** das bestehende Dishboard Design Manifest oder frühere SDDs. Diese bleiben Grundlage. Dieses Paket konkretisiert die Regeln für den Bereich **Wochenplan**; bei einem direkten Widerspruch haben die hier dokumentierten Wochenplan-Regeln für diesen Bereich Vorrang.

## Inhalt
- `01_SDD/WOCHENPLAN_SDD.md` – ausführliche Spezifikation
- `02_DESIGN_MANIFEST_UPDATE/WOCHENPLAN_DESIGN_MANIFEST_DELTA.md` – Design-Manifest-Ergänzung
- `03_CLAUDE_CODE/CLAUDE_CODE_WOCHENPLAN_PROMPT.md` – Umsetzungsauftrag
- `04_REFERENCES/IST/` – 5 aktuelle Screenshots des realen Wochenplan-Bereichs
- `04_REFERENCES/ZIELMOCKUP/` – aktuelles Zielmockup

## Referenzregel
Die IST-Bilder dokumentieren Probleme und vorhandene Fachfunktionen. Sie sind **keine Zielgestaltung**. Das Zielmockup zeigt die gewünschte Richtung; bestehende globale Dishboard-Regeln gelten zusätzlich.
