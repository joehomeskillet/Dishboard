# Referenzen

- `accepted-settings/`: vom Nutzer ausdrücklich akzeptierte reale Designsprache. **Höchste visuelle Priorität.**
- `current-modules/`: aktuelle problematische Module und Allergene; Fachlichkeit erhalten, Layout nicht kopieren.
- `current-weekplan/`: aktueller Wochenplan, Patientenplan, Wochenübersicht und Küchenkalender; dient Ist-Analyse.
- `generated-mockups/`: gemeinsam erarbeitete Zielbilder für Vereinfachung, Allergene, Module und Wochenplan. Interaktionsprinzipien übernehmen, nicht blind pixelgenau nachbauen.
