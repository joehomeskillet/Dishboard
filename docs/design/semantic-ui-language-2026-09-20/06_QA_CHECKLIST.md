# QA Checklist

- [ ] Keine neue sichtbare Zeichenkette ohne Translation Key.
- [ ] Gleiche Semantik verwendet denselben Registry-Key.
- [ ] Icon-only nur wenn erlaubt; Tooltip + aria-label vorhanden.
- [ ] Status nie nur über Farbe.
- [ ] Destruktive Aktion sichtbar beschriftet und bestätigt.
- [ ] Primäraktion pro Kontext eindeutig.
- [ ] Seltene Aktionen unter Mehr.
- [ ] Deutsche und englische Labels ohne Clipping.
- [ ] Keyboard-Fokus sichtbar.
- [ ] Mobile Kernworkflows ohne horizontales Scrollen.
- [ ] Allergene haben Code, Icon und A11y-Text.
- [ ] Empty/Error/Loading/Read-only/Offline-Zustände getestet.
- [ ] Fehlende Übersetzungen werden im Development sichtbar.
