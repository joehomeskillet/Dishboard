# Registry Guide

Dieses Paket enthält **184 standardisierte Semantiken**. `05_SEMANTIC_REGISTRY.csv` ist die leicht prüfbare Masterliste; JSON ist für direkte maschinelle Verarbeitung gedacht.

Einträge dürfen erweitert werden, aber nur nach Prüfung, ob bereits ein passender Key existiert. Die `tabler_icon`-Spalte ist ein Ziel-Mapping und muss gegen die im Projekt tatsächlich verfügbare Tabler-Version validiert werden. Falls ein vorgeschlagenes Icon fehlt, zentral auf das nächstpassende Icon mappen – nicht lokal im Template.
